Your layout.tsx is already set up correctly to render the Header component. The main issue is in your Header.tsx, specifically how you're exporting the component.

1. Fix the Header component
You currently have:

export default Header();

This calls the function immediately instead of exporting the component. It also doesn't provide the required title prop.

Change it to:

export default Header;

React and Next.js will handle calling the component when you render <Header title="Rewards" />.

2. Updated Header.tsx
Here's how I'd structure your header using Tailwind CSS while keeping your existing props.

import Image from "next/image";
import Link from "next/link";
import type { ReactNode } from "react";

type HeaderProps = {
  title: string;
  rightItems?: ReactNode[];
  navLinks?: ReactNode[];
};

const Header = ({ title, rightItems, navLinks }: HeaderProps) => {
  return (
    <header className="w-full border-b bg-white">
      <nav className="flex h-20 items-center justify-between px-6">
        {/* Left: Logo and Title */}
        <Link href="/" className="flex items-center gap-3">
          <Image
            src="/airasia-logo.png"
            alt="AirAsia Logo"
            width={64}
            height={64}
            priority
          />

          <span className="text-2xl font-bold text-gray-900">
            {title}
          </span>
        </Link>

        {/* Center: Navigation Links */}
        <div className="flex items-center gap-6">
          {navLinks?.map((link, index) => (
            <div key={index}>{link}</div>
          ))}
        </div>

        {/* Right: Actions */}
        <div className="flex items-center gap-4">
          {rightItems?.map((item, index) => (
            <div key={index}>{item}</div>
          ))}
        </div>
      </nav>
    </header>
  );
};

export default Header;

5. A few important React/Next.js concepts
Concept

Explanation

export default Header

Exports the component so React can render it.

HeaderProps

Defines which props your component accepts.

title: string

Required prop.

rightItems?

Optional prop, thanks to ?.

ReactNode[]

Allows you to pass an array of JSX elements.

navLinks?.map()

Renders each navigation item if the array exists.

children

Represents the page content rendered below your header.

One additional recommendation: Since you're building a reusable header, consider using ReactNode instead of ReactNode[] for navLinks and rightItems. That would let you pass either a single element or multiple elements without always creating an array.

Your overall component architecture is good: the layout owns the header, and the header accepts customizable content through props.

One important improvement
I removed your outer <Button> components because you don't need to nest a <Link> inside a <Button>.

Since you're already using buttonVariants(), the Link itself gets the exact same styling as a shadcn button.

This is cleaner HTML and avoids nesting interactive elements.

Tip: If you want the layout to work better on mobile, change the wrapper to:

<div className="flex flex-col gap-4 sm:flex-row sm:items-center sm:justify-between">

This stacks the heading and buttons on smaller screens while keeping them side by side on larger screens.

Gift Card Details Page	card-details.php	Display the details of one gift card, including its image, card name, card type, card value, and points required. Include a link to card-update.php. Only one details page is required. All gift-card links on the list page may lead to this one page.
